## ✨ Ürün Vizyonu (Product Overview)

**РУ́ССКИЙ**, klasik çoktan seçmeli dil uygulamalarının ötesine geçerek öğrenciyi gerçek Rusça konuşma senaryolarının, el yazısı (*Курси́в*) okuryazarlığının ve fonetik vurgu (*Ударе́ние*) refleksinin içine sokan tam kapsamlı bir **EdTech SaaS** ürünüdür.

Sıradan "karanlık mor AI şablonları" yerine, **Readymag**, **Kinfolk** ve İsviçre tipografik kurgusundan ilham alan **Tactile Swiss-Editorial** tasarım sistemiyle (`#F5F2EA` sıcak kağıt dokusu, `#18181B` keskin mürekkep hatları, `#CC2936` Moskova kırmızısı ve fiziksel gölge katmanları) sıfırdan tasarlanmıştır.

## 🚀 Öne Çıkan Özellikler (Key Features)

### 1. 🎙️ Gerçekçi Çok-Karakterli Sesli AI Koç & Hands-Free Telefon Modu
- **29 Özgün Senaryo & Cinsiyet Eşleşmeli Akustik Profiller:** Kahve siparişinden (`A1`) Moskova'da ev arkadaşlığına (`A2`), Rus aile sofrasından (`B1`) St. Petersburg'da beyaz geceler felsefesine (`C1`) ve Dostoyevski/Tarkovski tartışmalarına (`C2`) kadar 29 gerçek hayat senaryosu.
- **Gemini 2.5 Flash Native Audio (`ai().live.connect`):** Standart robotik TTS yerine gerçek zamanlı WebSocket ses sentezi. Her karakter (Ка́тя, Ди́ма, Ба́бушка Ни́на, Профе́ссор Ло́сев vb.) kendi yaşına, cinsiyetine ve duygusal tonuna uygun doğal insan sesiyle konuşur.
- **Hands-Free Telefon Görüşmesi Modu:** Ekrana dokunmadan karşılıklı sesli konuşma döngüsü (AI konuşur → mikrofon otomatik açılır → konuşmanız bittiğinde yanıtlar) ve görüşme sonunda **Konuşma Karnesi** (akıcılık skoru, telaffuz ve gramer analizi).

### 2. 🧠 Kişisel Hafıza, İlişki Barı (Affinity) ve Hata Defteri
- **Kalıcı Karakter Hafızası (`CharacterMemory`):** Karakterler önceki sohbetlerde söylediğiniz isminizi, şehrinizi ve ilgi alanlarınızı hatırlar; ilişki seviyeniz *Но́вый знако́мый* (🌱) seviyesinden *Свой челове́к* (💎) seviyesine yükselir.
- **Kişisel Hata Defteri (`MistakeLog`):** Sohbet veya ders sırasında yaptığınız gramer/vaka (*падежи́*) hataları otomatik kaydedilir; en sık yapılan hatalar için özel **Zayıf Nokta Antrenmanı (Weak-Spot Drill)** üretilir.

### 3. 🗺️ A1 → C2 (ТРКИ) Yapılandırılmış Müfredat & 3 Aşamalı Ders Motoru
- **6 Seviye, 21 Ünite, 60+ Ders:** Kiril alfabesi ve ses düşmelerinden (*о́канье / а́канье*) eylem görünüşlerine (*НСВ / СВ*), hareket fiillerinden (*глаго́лы движе́ния*) edebi Rusça ve ironiye kadar tam kapsamlı müfredat.
- **3 Aşamalı Ders Akışı:** Konu anlatımı ve kültür ipuçları → Sesli telaffuzlu kalıp kartları → Yazılı çeviri, durumsal yanıt ve mikrofonla sesli telaffuz testi.

### 4. 🏛️ Real Russia Immersion Studio (`/immersion`)
- **✍️ Rus El Yazısı Laboratuvarı (`Курси́в`):** Rusların günlük hayatta kullandığı el yazısını (*шинши́лла*, *лиши́шь* gibi ünlü harf tuzakları dahil) interaktif karşılaştırma ve deşifre egzersizleriyle öğretir.
- **🎧 Vurgu & Gölgeleme Stüdyosu (`Shadowing`):** Vurgu değiştiğinde anlamı tamamen değişen kelimeler (*за́мок* / *замо́к*, *му́ка* / *мука́*) ve sesli gölgeleme pratiği.
- **☕ Çift Sunuculu Günlük Podcast (`У́тренний Ко́фе`):** Ка́тя (`Kore` - Kadın) ve Ма́кс (`Puck` - Erkek) arasında geçen doğal sabah sohbetleri, tıklanabilir transkript ve anlama soruları.

### 5. 🔁 SM-2 Aralıklı Tekrar (SRS) & Seviye Tespit Sihirbazı (`/placement`)
- **SuperMemo-2 Algoritması:** Zorlandığınız kelimeleri daha sık, öğrendiklerinizi artan aralıklarla karşınıza çıkaran akıllı kart destesi.
- **Adaptif Seviye Tespit Sınavı:** 6 aşamalı (A1→C2) sınav ve hedef belirleme sihirbazı ile alt seviyeleri otomatik tamamlayıp doğrudan uygun seviyeden başlama.

## ⚡ Hızlı Kurulum (Local Development)

### 1. Depoyu Klonlayın ve Bağımlılıkları Yükleyin
```bash
git clone https://github.com/akkusahmet16/russkiy.git
cd russkiy
npm install
```

### 2. Ortam Değişkenlerini (`.env`) Ayarlayın
`.env.example` dosyasını `.env` olarak kopyalayın ve [Google AI Studio](https://aistudio.google.com/apikey) üzerinden aldığınız ücretsiz API anahtarınızı ekleyin:
```bash
cp .env.example .env
```
```env
GEMINI_API_KEY="AIzaSy..."
GEMINI_MODEL="gemini-3.1-flash-lite-preview"
DATABASE_URL="file:./dev.db"
```

### 3. Geliştirme Sunucusunu Başlatın
```bash
npm run dev
```
Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın. *(Not: API anahtarınızı dilerseniz doğrudan uygulama içindeki sol menüde yer alan **AI Anahtarı** modalından da girebilirsiniz).*

## 🌐 Vercel'e Deploy Etme (Production Deployment)

Proje **Vercel Serverless** ortamına %100 uyumludur (`process.env.VERCEL` algılandığında SQLite veritabanı ve TTS ses önbelleği otomatik olarak yazılabilir `/tmp` dizininde başlatılır).

1. Yukarıdaki **[Deploy with Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fakkusahmet16%2Frusskiy&env=GEMINI_API_KEY)** butonuna tıklayın veya kendi Vercel panelinizden **`Import Project`** diyerek bu GitHub reposunu seçin.
2. **Environment Variables** bölümüne `GEMINI_API_KEY` anahtarınızı ekleyin.
3. **Deploy** butonuna basın — saniyeler içinde kalıcı `.vercel.app` adresiniz hazır!
